# Stables testing release v0.0.14.046

Release date: 2026-10-25. Stables is one Android app: it runs its own built-in Minima node, or uses Minima Core on the same phone (official Minima Core 1.7.2 or later, or the older Minima Core app). A desktop app is coming. The MiniDapp is retired; v0.0.14.017 was the last release with a `.mds.zip`.

- `Stables_v0.0.14.046.apk`: the Android app. SHA-256 `49c2ef3fa05e47e3227ac9672c294cae2269102b6c978483049c3855a98f48e2`, signer certificate SHA-256 `dabb1b2a79b134b6008e6401735d649c140b51f2c4a83eb001b2ffdad5ce5dd4`.
- Download page: https://stablescouncil.org/#download

What is new: pay with the Stables card by scanning a code, over the Minima network and encrypted for the receiver; a tap that breaks is finished by itself; the screen lock while paying always opens with the slider; every coin is always counted in the Wallet total; card money survives a resync of the node. The Stables card is an experiment awaiting an independent security review.

Install over the existing app; do not uninstall or clear its data. Winiwa and xWiniwa are valueless test tokens.
