# Inter website bundle

**Family:** Inter  
**Version:** 4.1  
**Source:** `1_development/stream_2_community/task_x_thread_mother_of_all_food/fonts/Inter-4.1/`  
**License:** SIL Open Font License 1.1, copied as `LICENSE.txt`

The website bundles normal weights 400, 500, 600, 700, 800, and 900 as WOFF2 files. This removes
the public website's runtime dependency on Google Fonts and supplies every weight used by the D028
visual authority.
