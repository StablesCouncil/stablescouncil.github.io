# Stables v0.0.10.83 testing prerelease

This is a valueless testing build. Winiwa and xWiniwa are test assets with no monetary value. It
is not a stablecoin launch, trading release, production-readiness claim, or completion of the
formal three-wallet community rehearsal.

## Test packages

- `Stables_v0.0.10.83.apk`: standalone Android app with an embedded Minima node.
- `StablesCore_v0.0.10.83.apk`: Android app connected to the official Minima Core app. The tester
  must personally enable Stables in Minima Core. Mint, Burn, and Send also require Admin.
- `Stables_v0.0.10.83.mds.zip`: MiniDapp for installation in MinimaOS.
- Web: the same shared application source is ready for
  `https://stablescouncil.org/dapp/3-test/`, but that Council-authorized website deployment is
  still pending. The live site must not be treated as v0.0.10.83 until that deployment completes.
- Personal web preview: `https://charles0xhorizonxyz.github.io/new/` with the test app at
  `https://charles0xhorizonxyz.github.io/dapp/3-test/`.

Do not run the standalone embedded node and the official Minima Core node at the same time on one
phone. Choose either the standalone path or the Core-connected path for a test session.

Windows is not included in this prerelease. Its installer, Authenticode signing, network behavior,
and update chain are not yet release-ready.

## Android update protection

The standalone updater now requires HTTPS on an allowlisted host, validates every redirect,
requires the release SHA-256, checks the package name and increasing versionCode, verifies the APK
signer against the installed app and the published signer fingerprint, then cleanly shuts down the
embedded node before opening Android's installer. Any failed check stops the update.

## Known test boundary

- USDw, stablecoin mechanics, Exchange, Trade, liquidity, and wider protocol operations are not in
  this test.
- The Core-connected package has been release-signed, installed, launched, and registered against
  Minima Core 1.2.5 on a Pixel 7 Pro. Final Enable/Admin remains a user-controlled Core action.
- The standalone package updated in place from v0.0.10.01 with its existing data preserved and its
  embedded node cleanly stopped before and after installation.
- The formal three-independent-wallet signed rehearsal remains open. Treat this as an early testing
  prerelease and report any inconsistency before moving funds on a later production network.
