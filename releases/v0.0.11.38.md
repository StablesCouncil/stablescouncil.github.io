# Stables v0.0.11.38 testing prerelease

This is a valueless testing build. Winiwa and xWiniwa are test assets with no monetary value. It
is not a stablecoin launch, trading release or production-readiness claim.

## What is new since v0.0.10.83

- Network contribution: Pause, Minimum, Balanced (default) or Maximum decides how much the phone
  helps run Minima on battery; the charger always runs at full speed. Under it: TxPoW today and in
  total, time online today, the device hash rate and a daily chart.
- The open app uses about a third of the battery it did: one owner for the wallet balance read,
  repaints only when the screen changes, jobs that stop when told to, and a transaction mirror that
  pays for a decision once.
- Notes in your hands: each token on Wallet management has Manage, showing the exact notes with
  amount and age. Pick the notes, choose how many to end with, see the transaction size against
  the 64 KB network limit, and rebuild. Combines and splits appear in Activity.
- Errors in plain words: a transaction that is too large says so in kilobytes, names the limit and
  offers Manage notes.
- One placement rule for every action; a sheet closes with its Back, never a Cancel button; burn
  confirmations are red.
- Security: Payment protection and Confirmation policy as two sections, a one-level 3-block
  default, a cross to remove a level, the quick-pay undo notice above the navigation.
- Payments show the time each step completed; Broadcasted is its own step.

Install over the previous version. Do not uninstall: the wallet lives on the device.
